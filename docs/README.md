# 콘솔 환경에서 구현한 오목 게임

## 주요 기능
- 콘솔 기반 오목 게임 구현
- 2인용 플레이 지원
- 방향키 기반 커서 이동
- Space Bar를 이용한 돌 배치
- 흑돌/백돌 턴 교대 처리
- 5목 완성 시 승리 처리
- 보드가 가득 찬 경우 무승부 처리
- 이미 돌이 놓인 위치 입력 방지
- 33 금수 판정 및 입력 제한
- 패턴 점수 기반 AI 착수 위치 선택

## 조작 방법
↑ ↓ ← → : 커서 이동  
Space Bar : 바둑돌 배치

## 실행 환경
- C#
- .NET 8.0
- Windows Console
- Visual Studio 2022

## 실행 방법
- Visual Studio 2022에서 프로젝트를 열고 빌드 후 실행합니다.

## 개발 목적
- C# 콘솔 환경에서 보드 게임의 상태 관리, 턴 제어, 입력 처리, 승리 판정, 금수 판정, AI 착수 평가 로직을 분리하여 구현하는 연습을 위해 제작했습니다.
- 인터페이스 기반으로 사용자 플레이어와 AI 플레이어를 분리하고, 게임 진행 로직과 렌더링 로직을 독립적으로 구성하는 것을 목표로 했습니다..
